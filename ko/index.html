끄적끄적 디펜스 개인정보처리방침

운영주체: TeamDoodle
검토 대상: 로컬 비공개 테스트 버전 1.0.2 (버전 코드 2)
시행일: 미확정

본 문서는 한국 대상 로컬 비공개 테스트 빌드의 검토용 초안입니다. 확정·시행된 방침이 아니며, 처리 절차의 검토가 남아 있습니다.

이 초안은 끄적끄적 디펜스(이하 "게임")의 현재 빌드에서 확인한 로컬 저장과 진단 설정, 문의 경로를 설명합니다.

현재 빌드는 게스트 방식으로 기기에 게임 진행을 저장합니다. 계정 서버와 게임 진행 동기화는 연결되어 있지 않으며, Google·Apple 로그인 및 계정 연동은 이용할 수 없습니다. 현재 빌드에는 광고가 없습니다. 대상 이용자는 만 13세 이상 청소년과 성인입니다.

1. 처리하는 정보 항목 및 목적

구분 처리 항목 처리 목적
로컬 게스트 정보 기기에서 무작위 생성한 게스트 식별자와 로그인 방식 (PlayerPrefs 저장) 기기 내 게스트 이용 상태 유지
로컬 게임 이용 정보 진행도, 재화, 경험치, 강화, 전투·보상 기록 등 (기기의 save.json 저장) 게임 진행 상태 저장 및 불러오기
Unity Diagnostics 공식 제품 문서상 설치별 식별자, 크래시 로그, 앱 진단 및 성능 자료. 추가 권장 수집 활성 기간에 Unity Dashboard에서 1.0.1/build1의 설치 ID와 기기·OS·메모리·GPU·화면·언어·로케일·국가/지역 메타데이터, 1.0.2/code2의 설치 ID·세션·기기 메타데이터 및 진단 자료 수신 확인. 설정 변경 후 실제 수집 범위는 미검증 오류 분석 및 안정성 개선. 활성 Usage 설정에 따른 추가 이용은 아래 3절 참고
이메일 문의·피드백·삭제 요청 이용자가 이메일을 보내는 경우 발신 이메일 주소와 문의 내용 문의·피드백 및 요청 확인

게스트 식별자와 게임 진행은 현재 계정·진행 서버로 전송되지 않습니다. 로컬 저장과 Unity Diagnostics의 외부 진단 처리는 구분됩니다. 이 빌드를 "데이터 수집 없음"으로 안내하지 않습니다.

2. 정보 보유 및 이용 기간

로컬 정보는 기기의 앱 저장 영역에 저장됩니다. 앱 데이터 삭제·제거 및 백업·복원에 따른 실제 삭제 범위와 복구 동작은 아직 검증되지 않았습니다.

Unity 공식 Diagnostics 문서는 기본 보관 기간을 90일로 설명합니다. 이 제품 기준을 아래 추가 이용까지 동일하게 적용되는 확정 보관 기간으로 안내하지 않습니다. 추가 이용의 항목별 보관 범위, 실제 저장 국가와 문의 이메일의 보관·삭제 운영 기준은 검토 중입니다. 이 초안은 앱의 확정 보관 기간이나 삭제 완료 기한을 제시하지 않습니다.

3. 외부 서비스 이용

현재 빌드에서 확인한 외부 진단 설정은 다음과 같습니다.

서비스 제공업체 목적 및 확인 상태
Unity Diagnostics Unity 오류 분석 및 안정성 개선. 빌드 설정상 활성; 현재 Dashboard의 Collection settings는 Essential + Recommended, Additional Recommended Data는 ON

출시 소스와 일치하는 Unity 프로젝트의 Dashboard에서 Additional Recommended Data를 ON으로 복원하고 재확인했습니다. 현재 Collection settings는 Essential + Recommended이며 Essential 수집은 항상 활성입니다. Usage의 고객 중심 기능, 모델링·집계 인사이트, 기술 지원, 비즈니스 권장 사항도 모두 활성 상태입니다. Unity Ads의 추가 액세스는 허용되지 않았습니다. Google Analytics는 연결되어 있지 않습니다.

Unity 제품 문서상 Essential은 서비스 제공에 필요한 크래시 로그·텔레메트리·구성 메타데이터를, Additional Recommended는 이용 중인 서비스의 필수 범위를 넘는 추가 자료를 포함할 수 있습니다. 활성 Usage 설정은 집계·추상화된 개발자 간 기능, 익명 벤치마크·모델 개선, 기술 지원 및 비즈니스 추천 등 추가 목적의 이용을 허용합니다. 이 앱에서 실제 사용되는 항목과 제공·이용 범위는 별도 검토가 필요합니다.

데이터 보안 분류에서 추가 확인할 항목은 독립 처리에 들어가는 개인 연결 가능 필드와 익명화 시점, country/subdivision이 물리 위치 추정인지 단순 로케일인지, 추가 권장 수집이 기본 진단 4개 유형 외 앱 상호작용 등을 포함하는지입니다. Usage 활성이나 조건 수락만으로 기본 4개 유형 모두의 공유 여부를 확정하지 않습니다.

수집 설정 변경 전 com.teamdoodle.doodledefense의 1.0.1/build1에 이어 검토 대상 1.0.2/code2의 Android Play 설치 세션에서도 설치 ID·세션·기기 메타데이터 및 진단 자료의 실제 수신을 확인했습니다. 설정 전환 후 단말 동기화 여부, 실제 수집 범위 변화와 적용 지연은 미검증이며, 기존 수신 데이터는 삭제하지 않았습니다. 국가/지역 메타데이터의 출처와 신고 분류는 검토 중입니다.

Firebase Crashlytics와 GameAnalytics는 향후 계획이며 현재 빌드에는 해당 SDK가 없습니다. 계정 서버도 개발 중이며 현재 로컬 빌드에는 연결되어 있지 않습니다.

Unity 제품 기준의 참고 자료 (이 앱의 실제 운영 조건과는 별도):

  • Unity Diagnostics 개인정보 보호 개요
  • Unity Diagnostics Google Play 데이터 보안 자료
  • Unity 수집 설정 설명
  • Unity 추가 이용 설정 설명

4. 개인정보의 국외 이전

Unity Diagnostics의 외부 처리를 검토해야 합니다. 이 앱에 적용되는 이전받는 자, 국가, 항목, 방법·시점, 목적, 보유 기간, 법적 근거 및 이용자 선택 사항은 아직 확정되지 않았습니다.

5. 개인정보의 제3자 제공 및 처리위탁

기본 Diagnostics의 처리 관계와 활성 Usage에 따른 추가 이용 관계를 구분해야 합니다. Unity 원문은 특정 목적에 따라 별도의 개인정보처리자 관계가 적용될 수 있음을 설명하며, 실제 Usage 화면에는 controller-controller 조건 수락 표시가 확인됐습니다. 모든 처리를 위탁 또는 공유 없음으로 단정하지 않습니다. 구체적인 제공·위탁 관계와 국외 이전 조건은 검토 중입니다.

6. 정보 삭제

Unity Dashboard의 설치 ID별 Diagnostics 삭제 요청 경로는 확인했습니다. 실제 삭제는 실행하지 않았고 이용자 접수부터 완료까지 검증한 것은 아닙니다. 로컬 저장 정보와 문의 이메일의 삭제는 각각 별도 확인이 필요합니다.

7. 이용자의 권리 및 문의

개인정보 열람·정정·삭제·처리정지 관련 문의와 삭제 요청은 아래 이메일로 접수할 수 있습니다. 정보 식별·본인 확인 및 요청 처리 절차는 검토 중이며, 이 초안은 요청에 따른 삭제 완료를 보장하지 않습니다.

8. 로컬 데이터 및 삭제 안내

현재 빌드는 서버 계정과 Google·Apple 연동 정보를 만들지 않습니다. 이메일로 기기의 로컬 저장 정보를 원격 삭제할 수 있는 기능도 없습니다. 게임 화면의 LOCAL-0001은 공통 표시값으로, 삭제 요청용 고유 식별자가 아닙니다.

출시 빌드에 Unity 설치 ID 확인·문의 전달 수단을 반영하고 실기기 검증한 뒤, 운영자는 문의로 받은 Unity 설치 ID를 이용해 Unity 진단 데이터 삭제를 요청하는 절차를 적용할 예정입니다. 이는 로컬 게임 저장 및 서버 계정 데이터와 별개이며 즉시 삭제나 확정 처리일을 보장하지 않습니다. 자동 문의 양식은 아직 현 출시 빌드에서 제공·검증된 기능이 아닙니다.
