로컬 데이터 및 삭제 안내

게임: 끄적끄적 디펜스
운영주체: TeamDoodle
검토 대상: 로컬 비공개 테스트 버전 1.0.2 (버전 코드 2)

검토용 초안이며 확정된 삭제 절차가 아닙니다. 현재 빌드의 로컬 정보와 외부 진단 자료를 구분해 안내합니다.

1. 현재 빌드의 계정·저장 방식

게스트 식별자는 기기에서 무작위 생성해 PlayerPrefs에 저장하고, 게임 진행은 기기의 save.json에 저장합니다. 계정 서버·진행 동기화는 연결되어 있지 않으며 Google·Apple 연동도 이용할 수 없습니다. 이메일로 기기의 로컬 정보를 원격 삭제하는 기능은 없습니다.

개인정보 문의·삭제 요청 이메일

teamdoodle.dev@gmail.com

이메일로 문의·삭제 요청하기

2. 문의 시 유의사항

게임 화면의 LOCAL-0001은 공통 표시값으로 고유한 계정·설치 식별자가 아닙니다. 이 값으로 삭제 대상이나 본인을 식별할 수 없습니다. 안전한 정보 식별과 요청 처리 절차는 검토 중입니다.

비밀번호, 인증 토큰, 주민등록번호, 원본 저장 파일 등 민감한 정보나 불필요한 개인정보를 이메일로 보내지 마세요.

3. 삭제 범위를 구분해야 하는 정보

  • 기기의 로컬 게스트 식별자·로그인 방식 (PlayerPrefs)
  • 기기의 게임 진행·재화·강화·전투·보상 기록 등 (save.json)
  • Unity Diagnostics 자료: 설정상 활성; 수집 설정 변경 전 같은 프로젝트의 1.0.1/build1과 1.0.2/code2 수신 확인; 실제 삭제 처리 절차는 미검증
  • 이용자가 보낸 문의 이메일: 보관·삭제 운영 기준은 미확정

Firebase Crashlytics·GameAnalytics SDK는 현재 빌드에 없습니다. 로컬 정보 삭제와 외부 진단 자료 또는 문의 이메일 삭제는 서로 다른 범위입니다.

4. 로컬 삭제·복원 및 외부 진단 자료

앱 데이터 삭제·제거, 재설치, 기기·OS 백업 복원에 따른 실제 삭제와 복구 동작은 아직 검증되지 않았습니다. 따라서 특정 조작으로 모든 정보가 영구 삭제되거나 복구되지 않는다고 보장하지 않습니다.

Unity 제품 문서와 실제 ProjectNova Dashboard에서 설치 ID별 진단 자료 삭제 요청 경로를 확인했습니다. 삭제 실행이나 이용자 접수부터 완료까지의 검증은 하지 않았습니다. 사용자 삭제 요청은 위 이메일로 접수할 수 있습니다. 출시 빌드에 Unity 설치 ID 확인·문의 전달 수단을 반영하고 실기기 검증한 뒤, 운영자는 문의로 받은 Unity 설치 ID로 Unity 진단 데이터 삭제를 요청하는 절차를 적용할 예정입니다. 자동 문의 양식은 아직 현 출시 빌드에 제공·검증되지 않았습니다. 이 절차는 로컬 게임 저장 및 서버 계정 데이터와 별개이며 즉시 삭제나 확정 처리일을 보장하지 않습니다. 수집 설정 변경 전 1.0.2/code2의 Android Play 설치 세션에서 실제 진단 자료 수신도 확인됐습니다. 삭제 완료 기한이나 외부 자료·이메일 보관 기간은 확정되지 않았습니다.

Local Data and Deletion Information

Game: 끄적끄적 디펜스
Operator: TeamDoodle
Review scope: Local private test version 1.0.2 (version code 2)

This is a review draft, not a finalized deletion procedure. It distinguishes local information from external diagnostic data in the current build.

1. Accounts and Storage in This Build

A guest identifier is randomly generated on the device and stored in PlayerPrefs; game progress is stored in save.json on the device. There is no connection to an account server or progress synchronization, and Google and Apple linking are unavailable. There is no function to remotely delete local device data through email.

Privacy Inquiry and Deletion Request Email

teamdoodle.dev@gmail.com

Send an Inquiry or Deletion Request

2. Information for Inquiries

The in-game LOCAL-0001 is a shared display value, not a unique account or installation identifier. It cannot identify deletion targets or verify identity. Safe data identification and request handling procedures are under review.

Do not email passwords, authentication tokens, government-issued identification numbers, original save files, sensitive information, or unnecessary personal data.

3. Information Requiring Separate Deletion Review

  • Local guest identifier and login method on the device (PlayerPrefs)
  • Game progress, currency, upgrades, battle and reward records, etc., on the device (save.json)
  • Unity Diagnostics data: enabled in settings; receipt before the collection settings change for both 1.0.1/build1 in the same project and 1.0.2/code2 is confirmed; actual deletion handling procedures are unverified
  • Inquiry emails sent by users: operational retention and deletion rules are not finalized

Firebase Crashlytics and GameAnalytics SDKs are absent from this build. Deleting local information, external diagnostic data, and inquiry emails involves different scopes.

4. Local Deletion, Restoration, and External Diagnostics

Actual deletion and recovery behavior when clearing app data, uninstalling, reinstalling, or restoring device or OS backups has not yet been verified. No particular action is guaranteed to permanently delete all information or prevent recovery.

Unity's product documentation and the actual ProjectNova Dashboard confirm a route to request diagnostic data deletion by installation ID. No deletion was executed, and user submission through completion has not been verified. User deletion requests may be submitted to the email above. Once means of checking and forwarding the Unity installation ID are included in the release build and verified on a device, the planned procedure is for the operator to use the Unity installation ID received through an inquiry to request deletion of Unity diagnostic data. The automatic inquiry form is not yet provided and verified in the current release build. This is separate from local game saves and server account data. Immediate deletion or a fixed completion date is not guaranteed. Actual receipt of diagnostic data before the collection settings change is also confirmed from Android Play installation sessions of 1.0.2/code2. Deletion deadlines and retention periods for external data or emails are not finalized.
