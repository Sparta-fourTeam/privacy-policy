끄적끄적 디펜스 Privacy Policy

Operator: TeamDoodle
Review scope: Local private test version 1.0.2 (version code 2)
Effective date: Not finalized

This is a review draft for the local private test build intended for Korea. It is not a finalized or effective policy. Processing procedures still require review.

This draft describes the local storage, diagnostic settings, and contact route confirmed for the current build of 끄적끄적 디펜스 (the "Game").

The current build uses guest access and stores game progress on the device. It has no connection to an account server or game progress synchronization. Google and Apple sign-in and account linking are unavailable. The current build has no advertising. The target audience is adolescents and adults aged 13 and over.

1. Information Processed and Purposes

Category Information Purpose
Local Guest Information A randomly generated guest identifier and login method, stored on the device in PlayerPrefs Maintaining guest access on the device
Local Gameplay Information Progress, currency, experience, upgrades, battle and reward records, etc., stored in save.json on the device Saving and loading game progress
Unity Diagnostics The product documentation lists installation-specific identifiers, crash logs, app diagnostics, and performance data. While additional recommended collection was enabled, the Unity Dashboard confirmed receipt of installation ID and device, OS, memory, GPU, screen, language, locale, and country/region metadata for 1.0.1/build1, and installation IDs, sessions, device metadata, and diagnostic data for 1.0.2/code2. The actual collection scope after the settings change is unverified Error analysis and stability improvements
Email Inquiries, Feedback, and Deletion Requests The sender's email address and message content, if a user sends an email Reviewing inquiries, feedback, and requests

Guest identifiers and game progress are not currently sent to an account or progress server. Local storage is separate from external diagnostic processing by Unity Diagnostics. This build is not described as collecting no data.

2. Data Retention

Local information is stored in the app's storage area on the device. The actual effects of clearing app data, uninstalling, and backup or restoration on deletion and recovery have not yet been verified.

The Unity Diagnostics retention and deletion conditions applicable to this app and operational rules for retaining and deleting inquiry emails are under review. This draft does not specify a finalized app retention period or deletion deadline.

3. Third-Party Services

The following external diagnostic setting has been confirmed for the current build.

Service Provider Purpose and Verification Status
Unity Diagnostics Unity Error analysis and stability improvements. Enabled in build settings; the Dashboard currently shows Collection settings: Essential and Additional Recommended Data: OFF

In the Unity Dashboard project matching the release source, Additional Recommended Data was saved as OFF at 2026-10-13 16:52 UTC and rechecked. Collection settings currently shows Essential, and Essential collection is always enabled. All four Usage options are enabled: customer-centric features, modeling and aggregated insights, technical support, and business recommendations. Additional Access for Unity Ads has not been granted.

Before the collection settings change, following com.teamdoodle.doodledefense version 1.0.1/build1, receipt of installation IDs, sessions, device metadata, and diagnostic data is also confirmed from Android Play installation sessions of the current review build, 1.0.2/code2. There are no new sessions after the change yet, so changes to the actual collection scope and the propagation delay remain unverified. Previously received data has not been deleted. The source and reporting classification of country/region metadata are under review.

Firebase Crashlytics and GameAnalytics are future plans; their SDKs are absent from the current build. The account server is also under development and is not connected to this local build.

8. Local Data and Deletion Information

This build does not create server accounts or Google or Apple account links. It has no function to remotely delete local device data through email. The in-game LOCAL-0001 is a shared display value, not a unique identifier for deletion requests.
